# PAFF

PAFF is a full-stack web application focused on helping adults build meaningful platonic friendships and social connections.

The platform allows users to create profiles, discover other users with similar interests and life circumstances, express interest in connecting, and eventually communicate through the platform.

PAFF is being developed incrementally as both:

- A portfolio and interview-readiness project
- An exploration of whether technology can meaningfully improve the process of forming long-term friendships

The project is being built using:

- ASP.NET Core
- Angular
- PostgreSQL
- Docker
- GitHub Actions
- Azure

The primary objective is to demonstrate modern software development practices while building practical proficiency with technologies commonly found in enterprise SaaS environments.

## Product Vision

Many adults report difficulty forming new friendships despite wanting stronger social connections. Existing social platforms tend to focus on dating, professional networking, broadcasting content, or maintaining existing relationships.

Platonic Adult Friend Finder (PAFF) is intended to explore whether a platform built specifically for substantial adult friendship formation can help people discover and develop meaningful new social connections.

Users will eventually be able to:

- Create friendship-focused profiles
- Search and discover other users
- Filter profiles based on interests and preferences
- Express interest in connecting
- Form mutual matches
- Communicate through the platform
- Participate in future compatibility and friendship experiments

The project intentionally follows an incremental delivery approach. Each milestone introduces a small amount of functionality while maintaining a working, demonstrable application.

## Development Philosophy

PAFF is an employability project first and a product second.

The application is being built in small, demonstrable increments rather than attempting to deliver the final vision immediately. Each milestone is designed to produce a working artifact that can be demonstrated, discussed in interviews, and extended in future milestones.

The focus is on:

- Incremental delivery
- Modern software engineering practices
- Interview readiness
- Architectural understanding
- Practical proficiency with the target technology stack
